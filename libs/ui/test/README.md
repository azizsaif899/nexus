# 🧪 مجلد الاختبار - CRM Nxs Test Suite

## 📋 الوصف
مجلد شامل لاختبار جميع المكونات والميزات في نظام CRM Nxs

---

## 🗂️ الملفات

### 1. **TestPage.tsx**
صفحة رئيسية تجمع جميع الاختبارات

### 2. **components/UIComponentsTest.tsx**
- اختبار جميع مكونات Shadcn/ui (40+ مكون)
- Buttons, Inputs, Dialogs, Dropdowns, etc.

### 3. **components/ThemeTest.tsx**
- اختبار الثيم المظلم/الفاتح
- نظام الألوان Gray Scale
- Theme Toggle

### 4. **components/RTLTest.tsx**
- اختبار دعم RTL الكامل
- الخطوط العربية (IBM Plex Sans Arabic)
- التخطيط من اليمين لليسار

### 5. **components/ChartsTest.tsx**
- اختبار مخططات Recharts
- Line, Bar, Pie, Area Charts
- مع الثيم المظلم/الفاتح

### 6. **components/DnDTest.tsx**
- اختبار React DnD
- Drag & Drop Cards
- Sortable Lists

---

## 🚀 كيفية الاستخدام
