## 🔧 الأوامر الأساسية / Basic Commands

```bash
# التطوير / Development
npm run dev              # بدء الخادم / Start dev server (port 3000)

# البناء / Build
npm run build            # بناء للإنتاج / Build for production
npm run preview          # معاينة البناء / Preview production build

# التحقق / Verification
npm run verify           # التحقق من TypeScript / Check TypeScript
npm run type-check       # نفس الأعلى / Same as above

# التثبيت / Installation
npm install              # تثبيت المكتبات / Install dependencies
npm ci                   # تثبيت نظيف / Clean install
```
