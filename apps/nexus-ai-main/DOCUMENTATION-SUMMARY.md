## 🚀 جاهز للاستخدام

### خطوات البدء:

```bash
# 1. نسخ الملفات
cp examples/cloud-functions/*.ts functions/src/activepieces/
cp examples/react/*.ts apps/nexus-ai-main/src/

# 2. تثبيت التبعيات
cd functions && npm install axios rate-limiter-flexible

# 3. ضبط المتغيرات
# functions/.env
ACTIVEPIECES_URL=http://localhost:8080
ACTIVEPIECES_ADMIN_KEY=your_key

# 4. النشر
firebase deploy --only functions:activepiecesProxy

# 5. الاختبار
# افتح http://localhost:3000
```
