# 🚀 Nexus AI - طرق تشغيل الخادم

## الطرق المختلفة لتشغيل الخادم

### 1️⃣ **الطريقة الأسهل (اضغط مرتين)**

```
اضغط مرتين على: RUN-NEXUS.bat
```

- تنظيف تلقائي للمنفذ
- إعادة تشغيل تلقائية عند التوقف
- واجهة عربية سهلة

### 2️⃣ **التشغيل السريع**

```
اضغط مرتين على: QUICK-START.bat
```

- تشغيل فوري بدون أسئلة

### 3️⃣ **PowerShell المتقدم**

```powershell
./Start-Nexus.ps1
# أو للإعادة التلقائية
./Start-Nexus.ps1 -AutoRestart
```

### 4️⃣ **من خلال Terminal**

```bash
npx vite --port 3000 --host
```

## 🌐 **عنوان التطبيق**

<http://localhost:3000>

## ⚠️ **في حالة المشاكل**

1. اضغط مرتين على `RUN-NEXUS.bat`
2. أو شغل `./Start-Nexus.ps1`
3. أو افتح Terminal وشغل `npx vite --port 3000 --host`

## 🔧 **ميزات Scripts**

- ✅ تنظيف تلقائي للمنفذ 3000
- ✅ تنظيف الكاش
- ✅ إعادة تشغيل عند التوقف
- ✅ رسائل باللغة العربية
- ✅ معالجة الأخطاء
