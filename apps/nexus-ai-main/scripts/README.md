# 🚀 Nexus AI Scripts

## 📋 Available Scripts

### 🎯 **Master Control (Recommended)**
```bash
NEXUS-MASTER.bat
```
**Interactive menu with all options**

### 🔧 **Individual Scripts**

#### **Development**
- `start-dev.ps1` - Start development server (PowerShell)
- `comprehensive-start.ps1` - Advanced start with checks

#### **Maintenance**
- `kill-port.bat` - Kill processes on specific port
- `clean-cache.bat` - Clean cache and temporary files
- `clean.ps1` - Advanced cleaning (PowerShell)

#### **Diagnostics**
- `diagnose.ps1` - System diagnostics (PowerShell)

#### **Legacy**
- `launcher.bat` - Old launcher (deprecated)

## 🚀 **Quick Start**

```bash
# Best option - Interactive menu:
.\scripts\NEXUS-MASTER.bat

# Or direct commands:
.\scripts\kill-port.bat 3000
.\scripts\clean-cache.bat
npm run dev
```

## 📊 **Script Functions**

| Script | Function | Platform |
|--------|----------|----------|
| NEXUS-MASTER.bat | 🎯 All-in-one control | Windows |
| kill-port.bat | 🔫 Kill port processes | Windows |
| clean-cache.bat | 🧹 Clean cache | Windows |
| diagnose.ps1 | 🔍 System check | PowerShell |
| start-dev.ps1 | 🚀 Start server | PowerShell |

**Use NEXUS-MASTER.bat for everything! 🎉**
