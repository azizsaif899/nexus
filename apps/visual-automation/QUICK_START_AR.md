# ⚡ دليل البدء السريع - Quick Start Guide

## 🚀 خطوات التشغيل السريعة

### 1️⃣ التثبيت (مرة واحدة فقط)

```bash
# تثبيت التبعيات
npm install
```

⏱️ **الوقت المتوقع**: 2-3 دقائق

---

### 2️⃣ التشغيل

```bash
# تشغيل بيئة التطوير
npm run dev
```

✅ **افتح المتصفح على**: http://localhost:5173

---

### 3️⃣ البدء بإنشاء سير عمل

1. **اسحب عقدة** من الشريط الجانبي الأيمن إلى منطقة العمل
2. **اربط العقد** بالضغط على النقاط الصغيرة بين العقد
3. **اضبط الإعدادات** من لوحة الخصائص عند تحديد عقدة
4. **شغّل سير العمل** بالضغط على زر "▶ تشغيل" أعلى الشاشة

---

## 🎯 الميزات الأساسية

### 📍 منطقة العمل (Canvas)
- **سحب وإفلات** العقد
- **تكبير/تصغير** باستخدام عجلة الماوس
- **تحريك** الكانفا بـ Space + السحب أو زر الماوس الأوسط
- **شبكة ذكية** لتنظيم العقد

### 📦 أنواع العقد المتاحة (13 نوع)
1. **HTTP Request** - طلبات API
2. **Database** - قواعد البيانات
3. **Transform** - تحويل البيانات
4. **Condition** - شروط منطقية
5. **Loop** - حلقات تكرارية
6. **Trigger** - المحفزات
7. **Email** - إرسال بريد إلكتروني
8. **Webhook** - استقبال البيانات
9. **Schedule** - جدولة زمنية
10. **Filter** - تصفية البيانات
11. **Aggregate** - تجميع البيانات
12. **Split** - تقسيم البيانات
13. **Merge** - دمج البيانات

### 📑 القوالب الجاهزة (6 قوالب)
- **📧 Email Marketing Automation** - أتمتة التسويق بالبريد
- **🔄 Data Sync Between Systems** - مزامنة البيانات
- **👤 Customer Onboarding Flow** - تأهيل العملاء
- **📊 Daily Report Generation** - تقارير يومية
- **🔔 Alert System** - نظام التنبيهات
- **💾 Data Backup Workflow** - نسخ احتياطي

## ⌨️ اختصارات مفيدة

### أساسيات
- **Ctrl/Cmd + S** → حفظ
- **Ctrl/Cmd + Z** → تراجع
- **Ctrl/Cmd + Y** → إعادة
- **Delete** → حذف العقدة المحددة
- **Escape** → إلغاء التحديد

### التحكم في العرض
- **+** → تكبير
- **-** → تصغير
- **=** → إعادة تعيين الزوم
- **Ctrl/Cmd + L** → ترتيب تلقائي للعقد

### سير العمل
- **Ctrl/Cmd + R** → تشغيل
- **Ctrl/Cmd + .** → إيقاف
- **Ctrl/Cmd + Shift + T** → فتح القوالب
- **Ctrl/Cmd + Shift + A** → فتح التحليلات

## 🔧 إعداد ActivePieces (اختياري)

إذا كنت تريد التنفيذ الفعلي على ActivePieces:

### خطوة 1: تشغيل ActivePieces محلياً

```bash
# استنساخ المشروع
git clone https://github.com/activepieces/activepieces.git
cd activepieces

# تشغيل بـ Docker
docker-compose up
```

### خطوة 2: الاتصال من الواجهة

1. انقر على أيقونة **"⚙️ ActivePieces"** في شريط الأدوات
2. أدخل:
   - **API URL**: `http://localhost:3000`
   - **API Key**: احصل عليه من لوحة ActivePieces
3. انقر **"اتصال"**

✅ **الآن**: عند الضغط على "تشغيل"، سيتم التنفيذ الفعلي!

## 💡 نصائح سريعة

## 🐛 حل المشاكل الشائعة

### المشكلة: العقد لا تظهر في الشريط الجانبي
**الحل**: تأكد من أن الشريط غير مطوي (انقر الزر الدائري على الحافة)

### المشكلة: لا يمكن ربط العقد
**الحل**: تأكد من أنك تسحب من **دائرة Output** إلى **دائرة Input**

### المشكلة: سير العمل لا يعمل
**الحل**: 
1. تحقق من **اتصال العقد** بشكل صحيح
2. افتح **لوحة الخصائص** وتأكد من إعدادات كل عقدة
3. شاهد **Error Tracking** لمعرفة الخطأ

### المشكلة: الأداء بطيء
**الحل**:
1. أغلق **AI Chat** إذا لم تستخدمه
2. قلل **عدد العقد المفتوحة** (صغّر العقد غير المستخدمة)
3. استخدم **Ctrl/Cmd + R** لإعادة تحميل الصفحة
