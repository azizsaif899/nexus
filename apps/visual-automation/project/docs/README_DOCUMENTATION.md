### 2. 🤖 [دليل شريط الدردشة بالذكاء الاصطناعي](/docs/AI_CHAT_SIDEBAR.md)
**AI Chat Sidebar Complete Guide**

تعرف على:
- بنية السايد بار المعمارية
- تركيب وإعداد المساعد الذكي
- الميزات التفاعلية (دردشة، اقتراحات، توليد أكواد)

- الأمان وأفضل الممارسات

**مناسب لـ:** المطورين والمصممين

---

### 3. 🎛️ [دليل الأزرار والتحكمات](/docs/BUTTONS_AND_CONTROLS.md)
**Buttons and Controls Complete Guide**

شرح شامل لـ:
- شريط الأدوات العلوي (Toolbar)
- أدوات التحكم في الكانفا (Zoom, Pan, Fit)
- أزرار العقد ووظائفها
- لوحة الخصائص
- اختصارات لوحة المفاتيح (+30 اختصار)

**مناسب لـ:** جميع المستخدمين

---

### 4. 🎨 [دليل الهيكل والألوان](/docs/STRUCTURE_AND_COLORS.md)
**Structure and Colors Complete Guide**

دليل شامل يتضمن:
- البنية المعمارية الكاملة

- نظام الطباعة (خطوط عربية وإنجليزية)
- المسافات والتباعد
- الظلال والتأثيرات البصرية (Glassmorphism, Neumorphism)

**مناسب لـ:** المصممين والمطورين

---

### 5. 📦 [دليل العقد](/docs/NODES_GUIDE.md)
**Workflow Nodes Complete Guide**

تعلم كل شيء عن العقد:
- أنواع العقد الـ 4 الرئيسية
- بنية العقدة التفصيلية
- دورة حياة العقدة
- الاتصالات بين العقد
- معالجة الحالات والأخطاء

**مناسب لـ:** المطورين والمستخدمين المتقدمين

---

### 6. 🔨 [دليل إنشاء عقدة جديدة](/docs/CREATE_NEW_NODE.md)
**Creating New Node - Step by Step Guide**

## 🆕 الميزات الجديدة

### ✨ زر إنشاء عقدة جديدة (+)

تم إضافة زر "+" في السايد بار الجانبي لإنشاء عقد مخصصة بسهولة مع:
- اختيار نوع العقدة (Trigger, Action, Logic, Error Handler, Custom)
- تحديد التصنيف
- إدخال الاسم والوصف
- إعدادات ActivePieces كاملة

**الموقع:** سايد بار العقد → زر "+" بجانب الفئات

### 🖱️ التمرير الأفقي بالماوس

تم إضافة دعم التمرير الأفقي بالماوس في قائمة الفئات:
- اسحب بالماوس لليمين واليسار
- تجربة سلسة مثل Figma
- لا حاجة لشريط تمرير ظاهر

**الاستخدام:** اضغط واسحب على منطقة الفئات
