مركز إدارة تقارير الاختبارات - CRM Nxs Testing Suite

🎯 مرحباً بك في مركز التقارير!

هذا المجلد يحتوي على جميع تقارير الاختبارات المُنشأة تلقائياً.

للبدء، اتبع الخطوات التالية:

1
تشغيل التطبيق
npm run dev
2
فتح صفحة الاختبارات
http://localhost:5173/test
3
تشغيل الاختبارات
اضغط زر "تشغيل الكل" وانتظر حتى تكتمل جميع الاختبارات
4
حفظ التقرير
اضغط زر "حفظ التقرير" وسيتم تنزيل ملفي HTML و JSON
🧪 عرض كود صفحة الاختبارات 📖 قراءة الدليل الكامل

📁 الملفات في هذا المجلد:

📄 README.md - دليل استخدام مفصل
📊 test-report-example.json - مثال على بنية التقرير
🔒 .gitkeep - ملف Git للحفاظ على المجلد
🌐 index.html - هذه الصفحة (دليل التنقل)

💡 نصائح مهمة

📌 التقارير تُحفظ تلقائياً في مجلد التنزيلات

📌 احتفظ بتقرير يومي لمراقبة تطور الجودة

📌 استخدم ملف JSON للتكامل مع CI/CD
